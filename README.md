## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/fr0st-iwnl/mpv-config.git
   ```
3. **Move to the configuration folder:**

   ```bash
   cd mpv-config
   ```
4. **Copy the configuration files to your mpv directory:**

   ```bash
   cp -r * ~/.config/mpv/
   ```

## Customization

Feel free to modify the configurations in `mpv.conf` and `input.conf` to suit your preferences. For example, you can adjust the volume increment or modify keybindings as needed.
